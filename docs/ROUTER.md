# portfolio-treatise — router

An Astro site serving alexanderdbarclay.com: an illuminated treatise at the root and essays under `/writing/*`.
Deployed from `main`; essays and new catalogue entries are drafts awaiting Alex's review (see [state](state.md)).

## Where things live

- [index](index.md) lists every doc with one sentence each.
- [state](state.md): current position, decisions, dead ends, open items.
- [STATUS.md](STATUS.md): the live status, next steps, known gaps.
- [DESIGN-SYSTEM.md](../DESIGN-SYSTEM.md): tokens and components; the reference HTML wins on disagreement.
- [plans/](plans/): dated designs and plans for each build phase.
- `content/blog/`, `content/eidos/`: essays and specification; `claims.yaml`: the catalogue.
- [catalogue-additions.yaml](drafts/catalogue-additions.yaml): drafted entries, never built.
